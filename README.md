## ✨ Features

- 📊 **Interactive Analytics:** Visual sales charts and data insights powered by Recharts.
- 📦 **Inventory & Stock Tracking:** Effortlessly manage products, categories, and stock updates.
- 🔔 **Real-time Notifications & Alerts:** Interactive user feedback using SweetAlert2 and React Hot Toast.
- ⚡ **Lightning Fast Navigation:** Smooth multi-page routing handled by React Router v7.
- 📱 **Responsive UI:** Clean, fully adaptive layout crafted with Tailwind CSS v4.

---

## 🛠️ Tech Stack

- **Core Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4 (with `@tailwindcss/vite`)
- **Routing:** React Router v7
- **Data Visualization:** Recharts
- **Icons:** Lucide React
- **Notifications & UI Alerts:** SweetAlert2, React Hot Toast
